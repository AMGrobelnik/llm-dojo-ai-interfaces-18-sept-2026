# Claude Code ecosystem

- **Claude Code** — CLI coding agent the developer builds workflows and hooks around
- **Claude Agent SDK** — SDK for building custom Claude-based agents
- **Claude API (Anthropic SDK)** — Messages API client for direct model calls
- **Model Context Protocol (MCP)** — protocol for wiring external tools/servers into Claude
- **Claude Code skills** — packaged, invokable instruction sets
- **Claude Code hooks** — lefthook-based commit-time gate suite, vendored as a submodule
