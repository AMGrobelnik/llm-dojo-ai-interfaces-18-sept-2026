# CLI / desktop tools

- **tmux** — terminal multiplexer used to drive/inspect long-running sessions (both repos)
- **git** — version control (both repos)
- **LibreOffice (soffice)** — headless document/slide conversion (both repos)
- **pdftoppm** — renders PDF pages to images (both repos)
- **gh (GitHub CLI)** — GitHub operations from the command line (both repos)
