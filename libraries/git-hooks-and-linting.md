# Git hooks & linting tools

- **lefthook** — git hooks runner driving the shared commit-time gate suite
- **shfmt** — shell script formatter
- **shellcheck** — shell script static analysis
- **typos** — spelling-error checker for source and docs
- **gitleaks** — scans staged content for committed secrets
- **pip-audit** — scans resolved Python dependencies for known vulnerabilities
- **hadolint** — Dockerfile linter
- **actionlint** — GitHub Actions workflow linter
- **bandit** — Python security static analysis
- **rumdl** — Markdown linter
- **taplo** — TOML linter/formatter
- **tsgo** — native TypeScript type-checker used in CI-style gating
- **fallow** — dead-code scanner for the frontend
