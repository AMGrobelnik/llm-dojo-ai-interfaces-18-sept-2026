# Python

## Runtime & packaging
- **uv** — Python package/dependency manager and virtualenv tool
- **ruff** — Python linter and formatter
- **ty** — static type checker for Python
- **deptry** — flags unused and missing Python dependencies
- **import-linter** — enforces import/architecture boundaries
- **pydantic-to-typescript** — generates TS types from Pydantic models
