# User Guide

## Workflow

1. **Plan** - Break down tasks and create todo lists
2. **Execute** - Run tasks in parallel when possible
3. **Test/Validate** - Verify functionality
4. **Iterate** - Refine based on results

## Efficiency Tips

### Wispr Flow Integration

- Use Wispr Flow for dictation and hands-free operation
- Set speech shortcut to **Tab** (single unused key)

### Claude Code Optimization

- Maximize parallel task execution (Claude Code supports parallel tasks as of July 2025)
- Batch tool calls in single messages when possible
