## Acceptance CQs

Standing regen acceptance test (from the P0 scoping CQ set; whatever a tool-equipped baseline already answers
feeds Priors omitted above). Expected answers in parentheses.

1. Tokens vs a single chat, per Anthropic (~15×). 2. Factor explaining ~80% of variance (token usage).
3. Task type Anthropic flags as a poor MAS fit (shared context / many dependencies, e.g. most coding).
4. Representation ADAS searches in (code — a meta agent programs new agents). 5. Does ADAS claim cross-domain
transfer (yes — claimed; contested by 2026 evaluations). 6. Does MAD reliably beat CoT/self-consistency per
the 2025 critique (no). 7. What explains much of MAD's apparent benefit (aggregation). 8. The critique's
"universal antidote" (model heterogeneity). 9. MoA layer input (all outputs of the previous layer's agents).
10. Two evaluation shortcomings the MAD critique names (weak baselines; limited benchmark coverage;
inconsistent setups). 11. What Cognition says agents must share (full context / full agent traces).
12. Cognition's recommended alternative (a single-threaded linear agent). 13. MAST mode/category counts
(14 modes / 3 categories). 14. MAST's three categories (system design issues; inter-agent misalignment; task
verification). 15. MAST trace counts (taxonomy from 150; MAST-Data 1600+ across 7 frameworks). 16. Where the
failure locus moved per the 2026 survey (coordination — errors propagate across agents). 17. Bigger gain per
Anthropic: model upgrade or doubled token budget (model upgrade — vendor-scoped, not re-anchored here).
18. Task property that makes MAS worth the cost (heavy parallelization / breadth / exceeds one context
window / many tools). 19. MoA vs GPT-4 Omni on AlpacaEval 2.0 (65.1% vs 57.5%). 20. The "E" in LIFE (Evolve
via autonomous self-improvement). 21. What rarely happens after failures (they rarely translate into
structural self-improvement). 22. Three settled-canon methods a novelty claim must clear (debate;
